# Мастер-таймлайн Лавразії

## Хронологія (з урахуванням канон-рішень)

| Рік   | Подія                                                                   |
| ----- | ----------------------------------------------------------------------- |
| -60   | Початок 60-річної війни                                                 |
| -15   | Перша використання чорної мани (з відчаю держави, що мала капітулювати) |
| -40   | Становлення лабораторій S3.2 та M4.3                                    |
| 0     | Війна завершилася                                                       |
| 0+    | Ханна працює в лабораторіях, відкриває сита ману                        |
| 0+?   | Ханна та Любисток у закинутій лабораторії розробляють ситу ману; Ханна забирає її і йде |
| 0+?   | Любисток продовжує дослідження мани і створює двигун життєвої енергії   |
| 0+?   | Ханна підходить до гірського храму, проголошується богинею              |
| 0+?   | Дона та Мінерва (гравці) знищують Ханну на її ж м’ясорубці              |
| 0+?   | Амадей помер                                                            |
| +6    | Сьогоднішній день. Пройшло 21 рік від першого використання мани.        |
